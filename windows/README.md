# UAI for Windows

The Windows build of UAI — all your AI assistants (Claude, ChatGPT, Gemini,
DeepSeek, Muse, xAI, Grok Bot, Vercel v0, plus any you add) in one window,
signed in with your own accounts. It's a separate, Electron-based rebuild of
the macOS app (Swift can't run on Windows), with the same shell and features.

## Features
- Left rail of round AI icons + a **Universal AI** that routes your request to
  the best assistant (needs an Anthropic API key, set in Settings).
- Each AI keeps its own persistent login (your accounts, your chats).
- Back / forward / reload, a unified search bar, Ctrl +/–/0 zoom.
- **Media** tab: images your AIs generate are saved automatically; screenshots
  you attach land in a separate Screenshots tab.
- Reply **notifications** (Windows toast + the AI's unread badge).
- Links in replies open in your **default browser**; sign-in flows stay in-app.
- **+** to add any other AI by its web address; drag the icons to reorder.

## Build it
Built in CI on a Windows runner (`.github/workflows/build-windows.yml`,
manual-only). It produces `UAI-Setup-<version>.exe` (NSIS installer).

Locally:
```
cd windows
npm install
npm run dist      # installer in windows/dist/
npm start         # run without packaging
```

The app icon is generated by `scripts/make_icon.py` (committed as
`assets/icon.ico`); regenerate with `npm run icon` (needs Python + Pillow).

The installer is unsigned, so on first run Windows SmartScreen shows
"Windows protected your PC" → click **More info → Run anyway**.
